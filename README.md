# 每日任务计划（macOS 测试版）

一个用于规划每日工作与学习任务、记录“留一笔”的本地 Mac App。支持提前规划明日、按日期查看任务、添加照片和视频，以及将任务与媒体一并导出为 ZIP 备份。

## 下载

到 [Releases](https://github.com/halohong-ai/daily-task-plan/releases/tag/v1.0.0-beta.1) 下载 `daily-task-plan-macos-v1.0.0-beta.1.zip`。这是 **未经 Apple 公证的测试版**，仅支持 macOS 12 或更新版本，不支持 Windows。首次打开可能被 macOS 拦截。

文件 SHA-256：`38586e821b71d8b8eb3ca495e7944e179cfca11c0de94463a7b478313ddee2a9`

## 安装与首次打开

1. 解压下载的 ZIP，将“每日任务计划.app”拖入“应用程序”文件夹，然后尝试打开一次。
2. 如果 macOS 阻止打开，进入“系统设置”→“隐私与安全性”，向下找到该 App 的提示，点击“仍要打开”。
3. 再次确认“打开”。这只为这个 App 添加例外，不需要关闭系统的整体安全保护。

仅在确认文件来自本仓库且未被篡改时执行以上步骤。若系统提示文件已损坏，或没有出现“仍要打开”，不要运行终端命令强行跳过检查，请在本仓库提交 Issue。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 数据与备份

安装包不包含发布者的个人任务、留一笔或照片。请定期使用 App 内的 ZIP 导出功能自行备份数据。卸载或换电脑前，先确认备份文件可以妥善保存。
